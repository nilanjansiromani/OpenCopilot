## 🆕 Modal View Features

### How to Use
1. Open sidebar (Cmd+Shift+H)
2. Click ⛶ button in header
3. Sidebar closes, modal opens
4. Modal is centered, larger (80vw × 85vh)
5. Click X to close

### Modal Benefits
- **More space** for reading
- **Centered view** - easier on eyes
- **Same features** as sidebar
- **Better for long conversations**
- **Professional presentation**

### Modal vs Sidebar
| Feature | Sidebar | Modal |
|---------|---------|-------|
| Width | 30vw | 80vw |
| Height | 100vh | 85vh |
| Position | Right edge | Centered |
| Overlay | No | Yes (dark) |
| Best for | Quick queries | Deep reading |
