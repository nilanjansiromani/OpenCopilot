# 🚀 Installation Guide - Highlightr

## Super Simple Installation (No Build Required!)

This extension uses **vanilla JavaScript** with **no build process**, making installation incredibly simple.

### Step 1: Get the Code

**Option A: Clone with Git**
```bash
git clone https://github.com/yourusername/highlightr.git
cd highlightr
```

**Option B: Download ZIP**
1. Download the repository as a ZIP file
2. Extract it to a folder on your computer

### Step 2: Load in Chrome

1. Open Google Chrome
2. Navigate to `chrome://extensions/`
3. Enable **"Developer mode"** (toggle in the top-right corner)
4. Click **"Load unpacked"** button
5. Navigate to and select the `highlightr` folder (the root directory containing `manifest.json`)
6. Done! The extension is now installed 🎉

![Installation Steps](https://via.placeholder.com/800x400/1e3c72/ffffff?text=Load+Unpacked+→+Select+Folder+→+Done!)

### Step 3: Configure Your AI Service

1. Click the Highlightr extension icon in your Chrome toolbar
2. The settings page will open automatically (first time only)
3. Choose your AI service and enter your API key
4. Click "Save Settings"

## 🎯 That's It!

**No `npm install` needed**  
**No `npm run build` needed**  
**No webpack, babel, or any build tools**

Just load the folder directly into Chrome and you're ready to go!

## 🔄 Making Changes

If you want to modify the extension:

1. Edit any file (`.js`, `.html`, `.css`)
2. Go to `chrome://extensions/`
3. Find Highlightr extension
4. Click the refresh/reload icon 🔄
5. Your changes are live!

## 📋 Quick Checklist

- [ ] Folder extracted/cloned to your computer
- [ ] Chrome opened to `chrome://extensions/`
- [ ] Developer mode enabled
- [ ] Extension loaded using "Load unpacked"
- [ ] Extension icon visible in toolbar
- [ ] Settings configured with API key
- [ ] Ready to use! Press `Cmd+Shift+H` on any page

## 🆘 Troubleshooting

### Extension won't load
- Make sure you selected the root `highlightr` folder (containing `manifest.json`)
- Check that all files are present in the folder
- Try disabling and re-enabling the extension

### Can't see extension icon
- The extension may be hidden in the extensions menu
- Click the puzzle piece icon in Chrome toolbar
- Pin Highlightr to make it always visible

### "Manifest file is missing or unreadable"
- You selected the wrong folder
- Make sure you select the folder containing `manifest.json`

## 🎉 Success!

Once loaded, you should see:
- ⚡ Highlightr icon in your Chrome toolbar
- No errors in the extensions page
- Ability to open settings by clicking the icon

Now press `Cmd+Shift+H` (or `Ctrl+Shift+H`) on any web page to try it out!
