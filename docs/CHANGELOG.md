# Changelog

## Version 1.1.0 - UI Refresh & Gemini Support

### Added
- ✨ **Google Gemini Support**: Added full integration with Google's Gemini AI models
- 🎨 **New Professional Theme**: Replaced purple gradient with solid blue theme (#1e3c72)
- 🏷️ **Service Badge**: Sidebar now displays which AI service is currently active
- 📝 **Text Input for Models**: All model selections now use text input instead of dropdowns for flexibility

### Changed
- **Color Scheme**: Switched from purple gradient to professional blue (#1e3c72, #2a5298)
- **UI Framework**: Integrated Bootstrap 5.3.2 for consistent styling
- **Settings Design**: Completely redesigned settings page with card-based layout
- **Model Selection**: Changed from dropdowns to text inputs for all services

### Services Configuration
- **Groq**: Text input for custom model selection
- **Gemini**: New service with API key and model configuration
- **Ollama**: Text input for model names
- **OpenRouter**: Text input for flexible model selection

### UI Updates
- Service indicator badge in sidebar header with emojis:
  - 🚀 Groq
  - ✨ Gemini
  - 🦙 Ollama
  - 🌐 OpenRouter
- Solid color scheme throughout the extension
- Bootstrap-based responsive design
- Improved form controls and validation

## Version 1.0.0 - Initial Release

### Features
- Chrome extension with sidebar overlay (20% width)
- Multi-service AI support (Groq, Ollama, OpenRouter)
- Automatic HTML to Markdown conversion
- Quick action pills (Summarize, Bullet Points, New Terms)
- Keyboard shortcut: Cmd+Shift+H / Ctrl+Shift+H
- Context-aware page analysis
- ChatGPT-inspired UI
- Settings management with API key storage
